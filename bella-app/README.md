# Bella Finance (Android, Kotlin + Jetpack Compose)

Нативна реалізація прототипу `Bella App.dc.html` з handoff-пакета Claude Design.

Екрани: Головна, Капітал та Рахунки (+борги, переказ), Бюджет (Огляд / Операції / Звіт / Ліміти), Інвестиції, Цілі, Пасивний дохід, Калькулятор ОВДП.
Шити: нова операція / рахунок / борг / позиція, редагування, налаштування, довідка, імпорт виписки (.xlsx і CSV), безпека (PIN + біометрія, автоблокування).
Також: світла/темна тема, перемикач валюти, «приховати суми», скасування останньої зміни (до 20 кроків), збереження на пристрої.

Розумна аналітика (вкладка «Огляд» у «Бюджеті»): запас міцності, прогноз витрат, поради й топ-5 витрат. Курси НБУ (екран «Капітал та Рахунки»): живі курси USD, EUR, PLN з датою, ручне оновлення, автооновлення раз на 6 годин і конвертер. Для цього додано дозвіл `INTERNET`. Логіка винесена в `Analytics.kt` і `Rates.kt`, перевіряється юніт-тестами `AnalyticsTest` і `RatesTest`.

Операції в «Бюджеті»: дотик до операції відкриває редагування всіх полів (тип, сума, категорія, опис, дата, рахунок) і видалення. Операція прив'язується до рахунку: баланс рахунку змінюється автоматично під час додавання, редагування (старий вплив скасовується, новий застосовується) і видалення. Сума вводиться у валюті рахунку. Переказ між рахунками тепер теж операція типу «Переказ», її можна змінити або видалити. Старі й імпортовані операції без рахунку позначені як «Без рахунку» і на баланси не впливають, доки не призначити рахунок. У «Операціях» є фільтр за рахунком. Логіка — у `TxEdit.kt`, тести — `TxEditTest`.

Редагування з підказкою «як було»: у формах редагування операції, рахунку й позиції старе значення поля видно сірою підказкою, щойно поле порожнє; порожнє поле під час збереження лишається як було (`FormHints.kt`). У формі позиції обидві дати: для депозиту «Дата виплати відсотків» і «Дата повернення», для інших — «Наступна виплата» і «Погашення»; дати перевіряються (формат, виплата не пізніше повернення).

Депозит: вводиться одним полем «Сума депозиту» (без кількості). Галочка «Повторювати щомісяця» щомісяця в дату виплати створює дохід «Відсотки: …» (сума після податку 23%) на вибраний рахунок і переносить дату виплати на місяць уперед; пропущені місяці дораховуються під час запуску, після дати повернення виплати зупиняються, повтори не дублюються (`Deposits.kt`, тести `DepositsTest`). Форми додавання (позиція, рахунок, борг, переказ) показують, чого бракує, замість мовчазної відмови.

Готівка в портфелі: «Інвестиції» показують групу «Готівка» з рахунків із позначкою «Готівка» (галочка у формі рахунку). Суми беруться з рахунків і перераховуються за курсом НБУ; загальна сума портфеля = інвестиції + готівка, у капіталі нічого не дублюється. Звідти ж можна додати новий готівковий рахунок (`Portfolio.kt`, тести `PortfolioTest`).

ETF у валюті фонду: ціна купівлі й поточна вводяться у валюті фонду (USD, EUR, PLN або UAH), вартість у гривнях іде за курсом НБУ, прибуток показується окремо від ціни фонду й від курсу. За тікером у форматі Yahoo (VWCE.DE, SPY) ціну можна підтягнути кнопкою «Ціна з біржі» у формі або «Оновити ціни з біржі» в групі ETF; під час запуску ціни оновлюються автоматично раз на 6 годин. Джерело — неофіційний API Yahoo Finance, тож ручне введення ціни лишається (`Etf.kt`, тести `EtfTest`).

Версія: `versionName` задається в `app/build.gradle.kts` (зараз 1.1.0), номер збірки (`versionCode`) — кількість комітів у git (у CI потрібна повна історія, `fetch-depth: 0`), можна перевизначити змінною `BELLA_BUILD_NUMBER`. Версія, номер збірки й дата показуються внизу «Налаштувань».

## Збірка
Потрібні JDK 17 і Android SDK 34 (шлях до SDK: `ANDROID_HOME` або `sdk.dir` у `local.properties`). Відкрийте папку в Android Studio або з терміналу:

```
./gradlew :app:testDebugUnitTest   # юніт-тести
./gradlew :app:assembleDebug       # debug APK  -> app/build/outputs/apk/debug/
./gradlew :app:assembleRelease     # release APK -> app/build/outputs/apk/release/
```

### Підпис release
Без налаштувань `assembleRelease` дає непідписаний `app-release-unsigned.apk`. Щоб Gradle підписував сам:

1. Створіть ключ (один раз; **збережіть файл і паролі**, без них не оновити застосунок поверх встановленого):
   `keytool -genkeypair -keystore bella-release.jks -alias bella -keyalg RSA -keysize 2048 -validity 10000`
2. Скопіюйте `keystore.properties.example` у `keystore.properties` і заповніть (файл, `*.jks` та `*.keystore` ігноруються git). Або задайте змінні середовища `BELLA_KEYSTORE`, `BELLA_STORE_PASSWORD`, `BELLA_KEY_ALIAS`, `BELLA_KEY_PASSWORD` (зручно для CI).
3. `./gradlew :app:assembleRelease` дасть підписаний APK.

## Відхилення від прототипу
- Phosphor-іконки замінено на Material Icons (extended); шрифт Inter не вбудовано, використовується системний.
- Поля дат: текст `РРРР-ММ-ДД` замість `<input type=date>`.
- Відбиток пальця працює через системний `BiometricPrompt` (у прототипі імітувався).
- Курси валют, «сьогодні» (2026-11-02) і sparkline на головній закладені як у прототипі (статичні).
- Особисті дані карток (`ov` у прототипі) у код не перенесено; оверрайди рахунків накопичуються при редагуванні.
