# Фінансовий Менеджер

Персональний фінансовий застосунок у форматі однієї HTML-сторінки — без бекенду, без збірки, без залежностей окрім CDN-скриптів (Tailwind, Chart.js, Font Awesome, SheetJS).

Відкрийте `index.html` у браузері — і застосунок готовий до роботи.

## Можливості

- **Бюджет** — облік доходів/витрат з фільтрами (категорія, тип, валюта, пошук), сортуванням, inline-редагуванням, повторюваними щомісячними операціями та довільними категоріями
- **Net Worth** — загальний капітал з усіх джерел, історія капіталу в часі, реєстр активів з фільтрами й inline-редагуванням
- **Калькулятор ОВДП** — розрахунок реальної облігаційної математики (ціна, номінал, купон, YTM, графік виплат), власний список "Доступні ОВДП"
- **Інвестиції та Портфель** — калькулятор складного відсотка, портфель активів з фільтрами й сортуванням
- **Скарбничка / Цілі** — фінансові цілі з прогресом і накопиченням
- **Пасивний дохід** — розрахунок очікуваного пасивного доходу з портфеля (з урахуванням податку на депозити 23%), прогноз досягнення фінансової незалежності
- **Імпорт виписки з банку** (CSV/Excel) — автоматичне визначення стовпців, розпізнавання категорій із коментарів, фільтрація внутрішніх переказів
- Резервне копіювання/відновлення даних через JSON, експорт історії операцій у CSV

- **Розумна аналітика** (вкладка «Бюджет»): запас міцності в місяцях, прогноз витрат поточного місяця, поради (норма заощаджень 50/30/20, концентрація витрат, фінансова подушка) і п'ять найбільших витрат за вибраний період
- **Курси НБУ і конвертер** (вкладка «Net Worth»): курси USD, EUR, PLN з датою НБУ, кнопка «Оновити курси» (курси кешуються), конвертер між UAH, USD, EUR, PLN

## Що є в репозиторії

| Шлях | Що це |
| --- | --- |
| `index.html` | Вебверсія в одному файлі (цей README) |
| `bella-app/` | Нативний Android-застосунок (Kotlin, Jetpack Compose). Розумна аналітика і живі курси НБУ додані на екранах «Бюджет» і «Капітал та Рахунки» |
| `bella-mobile/` | Нова версія 1.34 у вигляді PWA з Android-обгорткою, тестами й документацією (окремий README) |
| `docs/analiz-repozytoriiv.md` | Звіт: що порівняно, що перенесено, що свідомо ні |

## Зберігання даних

Усі дані зберігаються локально в `localStorage` браузера — нічого не надсилається на жоден сервер.
