# Фінансовий Менеджер (Bella Finance)

**Fin-men-v.3 — основний репозиторій проєкту.** Головний застосунок — нативний Android `bella-app` (Kotlin, Jetpack Compose). Поруч лежать вебверсія (PWA) і старий односторінковий прототип.

## Що є в репозиторії

| Шлях | Що це | Статус |
| --- | --- | --- |
| `bella-app/` | Нативний Android-застосунок (Kotlin, Jetpack Compose). Окремий README зі збіркою й підписом | **Основний** |
| `bella-mobile/` | PWA версії 1.34 з Android-обгорткою, тестами й документацією (окремий README). Публікується на GitHub Pages | Вебверсія й еталон функцій |
| `index.html` | Старий прототип в одному файлі (Tailwind, Chart.js). Після публікації доступний за адресою `/legacy/` | Застарілий, лише підтримка |
| `docs/analiz-repozytoriiv.md` | Звіт: що порівняно, що перенесено, що свідомо ні | Довідка |

Репозиторії [**Bella**](https://github.com/bratan4ik-star/Bella), [**bella-mobile**](https://github.com/bratan4ik-star/bella-mobile) і [**New-fin-manager-BELLA-**](https://github.com/bratan4ik-star/New-fin-manager-BELLA-) тепер лише архівні джерела (у кожного вгорі README є позначка): нова розробка йде тут.

## Основні можливості

- **Бюджет**: доходи й витрати, фільтри, ліміти, звіт за період, повторювані операції, масові дії (зміна категорії, видалення), «Вільно до кінця місяця» (з урахуванням лімітів і запланованих повторюваних витрат), порівняння категорій з минулим місяцем, правила категорій для імпорту, річний звіт з експортом у Excel, синхронізація ETF, грошей і дивідендів з Interactive Brokers, сповіщення про 80% і 100% ліміту та терміни боргів.
- **Розумна аналітика** (вкладка «Огляд» у «Бюджеті»): запас міцності в місяцях, прогноз витрат поточного місяця, поради (норма заощаджень 50/30/20, концентрація витрат, фінансова подушка) і п'ять найбільших витрат періоду.
- **Капітал та Рахунки (Net Worth)**: рахунки, перекази, борги, історія капіталу.
- **Курси НБУ і конвертер**: курси USD, EUR, PLN з датою, ручне оновлення (у `bella-app` ще й автоматично раз на 6 годин), конвертер між UAH, USD, EUR, PLN.
- **Калькулятор ОВДП**: ціна, купон, YTM, графік виплат.
- **Interactive Brokers** (у `bella-app`): синхронізація позицій, грошей і дивідендів через Flex Web Service; графіки рахунку з перемикачем від 7 днів до 5 років — вартість і внесене, дохідність TWR, ціни ETF, розподіл і прибуток за позиціями.
- **Інвестиції** (з цільовим розподілом і порадами з ребалансування), **цілі, пасивний дохід** (податок на депозити 23%), імпорт банківської виписки (Excel/CSV), резервні копії JSON.

## Як запустити

- **Android (основний):** див. `bella-app/README.md`. Тести: `./gradlew :app:testDebugUnitTest`.
- **PWA:** `cd bella-mobile/app && python3 -m http.server 8000`, потім відкрити `http://localhost:8000`. Тести: `cd bella-mobile && npm install && npm test`.
- **Старий прототип:** відкрити `index.html` у браузері.

## Публікація

Робочий процес `.github/workflows/deploy-pages.yml` після кожного пушу в `main` публікує на GitHub Pages:

- корінь сайту — PWA з `bella-mobile/app/`;
- `/legacy/` — старий `index.html`.

Сайт не містить ваших даних: вони зберігаються лише на пристрої користувача, на сервер нічого не надсилається.

## Зберігання даних

Усі дані зберігаються локально (`localStorage` у вебверсіях, внутрішнє сховище в `bella-app`). Єдині зовнішні запити: курси НБУ (`bank.gov.ua`) і, за бажанням, синхронізація PWA через Google Drive.
