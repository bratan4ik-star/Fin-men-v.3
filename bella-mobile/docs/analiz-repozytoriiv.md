# Аналіз репозиторіїв і перенесення в нову версію (bella-mobile 1.34)

Нова версія програми: **bella-mobile** (PWA + Android-обгортка).
Переглянуто: New-fin-manager-BELLA-, Bella, Fin-men-v.3, bella-mobile.

## Що є в кожному репозиторії

| Репозиторій | Що це | Висновок |
| --- | --- | --- |
| **bella-mobile** | PWA (`app/`, React-рушій Claude Design) + Android-обгортка (`android/`, `bella-android/`), тести Playwright, CI для APK | Найповніша версія. Основа нової версії. |
| **Bella** | Один `index.html` (Tailwind, Chart.js): бюджет, Net Worth, ОВДП, складний відсоток, цілі, пасивний дохід | Ранній прототип. Усе вже є в bella-mobile. |
| **Fin-men-v.3** | Той самий `index.html` + нативний `bella-app` (Kotlin, Compose) + деплой на GitHub Pages | Дублікат Bella плюс нативна реалізація прототипу. Нового функціоналу немає. |
| **New-fin-manager-BELLA-** | Нативний Android (Kotlin, Compose, Room): аналітика, курси НБУ, імпорт Monobank/ПриватБанк, біометрія | Джерело двох ідей, яких не було в bella-mobile. |

## Що вже є в bella-mobile (переносити не треба)

Звірено за кодом, а не за назвами:

- складний відсоток (Інвестиції);
- покриття витрат пасивним доходом і прогноз досягнення цілі (Пасивний дохід);
- цільовий розподіл і ребалансування, карта портфеля, граф «Зв'язки»;
- ліміти витрат, правила категорій, повторювані операції, масові дії;
- «Вільно до кінця місяця», звіт за період, експорт у Excel;
- історія капіталу, рахунки, перекази, борги;
- світла й темна тема, «Приховати суми», PIN, біометрія в APK, шифрування;
- журнал змін зі скасуванням, копії JSON і Drive, довідка;
- імпорт виписки (Excel/CSV), курси НБУ для USD/EUR/PLN (без видимого інтерфейсу).

## Що перенесено (версія 1.34)

1. **Розумна аналітика** (з `AnalyticsScreen.kt`), «Бюджет» → «Огляд»:
   запас міцності в місяцях, прогноз витрат місяця й витрати на день, три поради
   (50/30/20, концентрація витрат, фінансова подушка), топ-5 витрат періоду.
2. **Курси НБУ і конвертер** (з `ExchangeRatesScreen.kt`), Net Worth:
   видимі курси з датою НБУ, кнопка «Оновити курси» (з повідомленням про помилку без мережі),
   конвертер між UAH, USD, EUR, PLN.

Також: версія кешу `fin-v34`, копія змін у `bella-android/www/`, опис у `README.md`,
18 сценаріїв у `tests/smoke.mjs` (нові: розумна аналітика, курси й конвертер).
Результат: `npm test` — усі перевірки та тести карт проходять.

## Що свідомо не переносилось

| Ідея | Причина |
| --- | --- |
| Room/SQLite замість `localStorage` | Не підходить для PWA. Ключ `bella_proto2` змінювати не можна, дані користувачів зникнуть. |
| Додаткові валюти (GBP, CHF, CZK, CAD) | Весь застосунок побудований на 4 валютах (UAH, USD, EUR, PLN). Потрібне окреме рішення, а не дрібна правка. |
| Шаблони виписок Monobank/ПриватБанк (`StatementParser.kt`) | Імпорт Excel/CSV у bella-mobile вже визначає стовпці автоматично. Варто звірити на реальних виписках, яких у репозиторіях немає (їх прибрано через особисті дані). |
| Деплой на GitHub Pages (Fin-men-v.3) | У README bella-mobile сказано, що публічного сайту немає: дані лише на пристрої. |
| Нативні екрани Kotlin | Інша технологія. Корисні лише як референс логіки. |

## Рекомендації на далі

1. Перевірити нові блоки на телефоні з реальними даними (автоматично перевірено в Chromium).
2. Решту модульних тестів з нативних проєктів (`OvdpMathTest`, `StatementParserTest`) можна перенести як сценарії в `tests/`, щоб зафіксувати математику ОВДП і розбір виписок.
3. Якщо потрібні додаткові валюти, спершу вирішити, як їх зберігати в рахунках і операціях.
